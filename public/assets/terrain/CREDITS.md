# Pinebend River terrain assets

The terrain uses compressed versions of these Poly Haven photographic textures, released under [CC0](https://polyhaven.com/license).

| Local image | Source | Creator |
| --- | --- | --- |
| dry_river_pebbles.webp | [Dry River Pebbles](https://polyhaven.com/a/dry_river_pebbles) | Amal Kumar |
| forest_ground_04.webp | [Forest Ground 04](https://polyhaven.com/a/forest_ground_04) | Rob Tuytel and Rico Cilliers |
| mossy_rock.webp | [Mossy Rock](https://polyhaven.com/a/mossy_rock) | Rob Tuytel |
| fir-bark.webp | Bark from [Fir Tree 01](https://polyhaven.com/a/fir_tree_01) | Rob Tuytel and Rico Cilliers |

The tree atlas, spruce bough cutout and alpine skyline were generated for Stillwater with OpenAI ImageGen. The source images were cropped and compressed for the game. The near-bank tree geometry, exposed roots, fallen timber, stones, sedges and riverbanks are generated by the game's landscape code.

The granite outcrops use [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01) by Kless Gyzen under [CC0](https://polyhaven.com/license). All six granite scans were simplified in Blender for runtime instancing.
